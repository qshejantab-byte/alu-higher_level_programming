# python-everything_is_object

Higher-level programming project on objects, references, mutable and
immutable types in Python 3.

## Tasks

Tasks 0-18 and 20-28 are one-line `.txt` answer files (no shebang)
answering conceptual questions about identity, equality, mutability,
and how Python passes arguments to functions.

| File | Description |
| --- | --- |
| `19-copy_list.py` | Return a copy of a list (max 3 lines) |

Task 29 (blog post) is not included here since it requires publishing
externally on Medium or LinkedIn.

## Requirements

- Ubuntu 20.04 LTS, Python 3.8.5
- pycodestyle 2.7.*
- `.py` files start with `#!/usr/bin/python3` and are executable
- `.txt` files contain a single line, no shebang
