# python-classes

Higher-level programming project on Object Oriented Programming in Python 3.

## Description

This project introduces the basics of Object Oriented Programming (OOP)
in Python: classes, objects, instances, attributes, methods,
`self`, the `__init__` method, data abstraction/encapsulation/
information hiding, private/protected/public attributes, properties,
and getters/setters.

## Tasks

| File | Description |
| --- | --- |
| `0-square.py` | Empty `Square` class |
| `1-square.py` | `Square` with a private `size` attribute |
| `2-square.py` | `Square` with validation on `size` |
| `3-square.py` | `Square` with an `area` method |
| `4-square.py` | `Square` with `size` as a property |
| `5-square.py` | `Square` that can print itself with `#` |
| `6-square.py` | `Square` with a `position` property |

## Requirements

- Ubuntu 20.04 LTS, Python 3.8.5
- pycodestyle 2.7.*
- All modules, classes and functions are documented
- All files start with `#!/usr/bin/python3` and are executable
