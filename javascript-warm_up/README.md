# JavaScript - Warm up

This folder has my solutions for the JavaScript warm up tasks.

## Files

| File | Description |
| --- | --- |
| 0-javascript_is_amazing.js | Prints "JavaScript is amazing" from a constant |
| 1-multi_languages.js | Prints 3 languages on 3 lines |
| 2-arguments.js | Prints a message depending on the number of arguments |
| 3-value_argument.js | Prints the first argument |
| 4-concat.js | Prints two arguments as "a is b" |
| 5-to_integer.js | Prints the first argument as an integer |
| 6-multi_languages_loop.js | Prints 3 languages with an array and a loop |
| 7-multi_c.js | Prints "C is fun" x times |
| 8-square.js | Prints a square of X |
| 9-add.js | Adds two integers |
| 10-factorial.js | Recursive factorial |
| 11-second_biggest.js | Finds the second biggest integer in the arguments |
| 12-object.js | Updates the value of an object |
| 13-add.js | Exports an add function |

## Run

```
./8-square.js 4
```

The code follows the semistandard style.
