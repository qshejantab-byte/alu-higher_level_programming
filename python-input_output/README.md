# python-input_output

Higher-level programming project on file I/O and JSON serialization
in Python 3.

## Tasks

| File | Description |
| --- | --- |
| `0-read_file.py` | Read a text file and print its content |
| `1-write_file.py` | Write text to a file, returns chars written |
| `2-append_write.py` | Append text to a file, returns chars added |
| `3-to_json_string.py` | Serialize an object to a JSON string |
| `4-from_json_string.py` | Deserialize a JSON string to an object |
| `5-save_to_json_file.py` | Save an object as JSON to a file |
| `6-load_from_json_file.py` | Load an object from a JSON file |
| `7-add_item.py` | Append CLI args to `add_item.json` |
| `8-class_to_json.py` | Describe an object's attributes as a dict |
| `9-student.py` | `Student` class with a `to_json()` method |
| `10-student.py` | `Student` with a filterable `to_json(attrs)` |
| `11-student.py` | `Student` with `reload_from_json()` |
| `12-pascal_triangle.py` | Compute Pascal's triangle |

## Requirements

- Ubuntu 20.04 LTS, Python 3.8.5
- pycodestyle 2.7.*
- All modules, classes and functions are documented
- All files start with `#!/usr/bin/python3` and are executable
