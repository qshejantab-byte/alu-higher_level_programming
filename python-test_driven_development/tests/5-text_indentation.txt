The ``text_indentation`` function
==================================

Import the function:

    >>> text_indentation = __import__('5-text_indentation').text_indentation

Basic usage:

    >>> text_indentation("Hello. How are you? I am fine: thanks.")
    Hello.
    <BLANKLINE>
    How are you?
    <BLANKLINE>
    I am fine:
    <BLANKLINE>
    thanks.
    <BLANKLINE>

Empty string prints nothing:

    >>> text_indentation("")

Text with no punctuation:

    >>> text_indentation("Hello world")
    Hello world

text must be a string:

    >>> text_indentation(12)

    >>> text_indentation(["a", "b"])
