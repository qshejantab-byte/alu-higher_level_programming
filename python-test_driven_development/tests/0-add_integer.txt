The ``add_integer`` function
=============================

Import the function:

    >>> add_integer = __import__('0-add_integer').add_integer

Basic addition:

    >>> add_integer(1, 2)
    3

    >>> add_integer(100, -2)
    98

Default value for b:

    >>> add_integer(2)
    100

Floats get casted to int:

    >>> add_integer(100.3, -2)
    98

    >>> add_integer(2, 3.9)
    5

    >>> add_integer(1.5, 1.5)
    2

Negative numbers:

    >>> add_integer(-10, -5)
    -15

    >>> add_integer(4, "School")

    TypeError: b must be an integer

    Traceback (most recent call last):
