The ``matrix_divided`` function
================================

Import the function:

    >>> matrix_divided = __import__('2-matrix_divided').matrix_divided

Basic division:

    >>> matrix = [[1, 2, 3], [4, 5, 6]]
    >>> matrix_divided(matrix, 3)
    [[0.33, 0.67, 1.0], [1.33, 1.67, 2.0]]

Original matrix is not modified:

    >>> matrix
    [[1, 2, 3], [4, 5, 6]]

Division with floats:

    >>> matrix_divided([[1.5, 3.0], [4.5, 6.0]], 2)
    [[0.75, 1.5], [2.25, 3.0]]

Division by a float divisor:

    >>> matrix_divided([[10, 20], [30, 40]], 2.5)
    [[4.0, 8.0], [12.0, 16.0]]
