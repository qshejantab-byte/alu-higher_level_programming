# JavaScript - Objects, Scopes and Closures

This folder has my solutions for the JavaScript objects, scopes and closures tasks.

## Files

| File | Description |
| --- | --- |
| 0-rectangle.js | Empty class Rectangle |
| 1-rectangle.js | Rectangle with width and height |
| 2-rectangle.js | Empty object if w or h is not a positive integer |
| 3-rectangle.js | Adds print() that draws the rectangle with X |
| 4-rectangle.js | Adds rotate() and double() |
| 5-square.js | Square that extends Rectangle |
| 6-square.js | Square with charPrint(c) |
| 7-occurrences.js | Counts how many times an element is in a list |
| 8-esrever.js | Reverses a list without using reverse |
| 9-logme.js | Prints how many arguments were logged and the new one |
| 10-converter.js | Converts a number from base 10 to another base |

## Run

Each file is run with Node.js and a main file, for example:

```
./3-main.js
```
