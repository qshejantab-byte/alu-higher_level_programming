# JavaScript - Web jQuery

This folder has my solutions for the JavaScript jQuery tasks.

## Files

| File | Description |
| --- | --- |
| 0-script.js | Turns the header red with document.querySelector (no jQuery) |
| 1-script.js | Turns the header red with jQuery |
| 2-script.js | Turns the header red when DIV#red_header is clicked |
| 3-script.js | Adds the class red to the header when DIV#red_header is clicked |
| 4-script.js | Toggles the header class between red and green |
| 5-script.js | Adds an li to UL.my_list when DIV#add_item is clicked |
| 6-script.js | Changes the header text when DIV#update_header is clicked |
| 7-script.js | Shows a Star Wars character name in DIV#character |
| 8-script.js | Lists all Star Wars movie titles in UL#list_movies |
| 9-script.js | Shows the French hello in DIV#hello |

## Run

Each script is loaded by an HTML file in the browser. Tasks 1 to 9 need jQuery:

```
<script src="https://code.jquery.com/jquery-3.2.1.min.js"></script>
```
