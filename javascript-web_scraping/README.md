# JavaScript - Web scraping

This folder has my solutions for the JavaScript web scraping tasks.

## Files

| File | Description |
| --- | --- |
| 0-readme.js | Reads a file and prints its content |
| 1-writeme.js | Writes a string to a file |
| 2-statuscode.js | Prints the status code of a GET request |
| 3-starwars_title.js | Prints the title of a Star Wars movie by ID |
| 4-starwars_count.js | Prints the number of movies with Wedge Antilles |
| 5-request_store.js | Saves the body of a webpage to a file |
| 6-completed_tasks.js | Counts completed tasks per user |

## Setup

The scripts that make requests use the `request` module:

```
npm install request
```

## Run

```
./2-statuscode.js https://alu-intranet.hbtn.io/status
```
